# QuickLearn

A personal study website at https://jaival10.github.io/quicklearn/ . Upload a PDF, photo of notes, TXT, or Markdown file; paste text; dictate a transcript; or paste a YouTube transcript. QuickLearn builds guided lessons, notes, flashcards, quizzes, and a two-speaker podcast script.

## Privacy and costs

The website is public, but lessons, progress, and original uploaded files are kept in **your browser's storage**. There is no QuickLearn account or server-side lesson database. Someone using the same browser profile can see your lessons. Clearing browser data removes them, so export a backup regularly. Backups contain lesson and source text, but not original uploaded files.

Cloud AI is optional and uses Puter with DeepSeek. Choosing it sends extracted source text to that service and may require a separate Puter sign-in. Its free monthly allowance is limited; additional usage may not be free. Basic source review works without an AI account. The local Windows edition can also use Ollama on that computer. QuickLearn does not use ChatGPT or require an OpenAI account.

Handwriting recognition runs in the browser with bundled OCR files. Review and correct the recognized text before generation. It may miss difficult handwriting. PDF files are limited to 20 pages and uploads to 30 MB. YouTube requires a manually pasted transcript; automatic video transcription is not available. The podcast uses the browser's live speech voices, not downloadable generated audio.

To move lessons between devices, export a backup on one device and import it on the other. There is no automatic sync.
